개인정보처리방침

시행일: 2026년 11월 14일

AI Music은 운영자가 관리하는 YouTube 채널의 콘텐츠 제작과 업로드를 지원하는 로컬 애플리케이션입니다. 본 방침은 앱 및 공개 안내 페이지의 데이터 처리에 관한 내용을 설명합니다.

1. 처리하는 정보와 목적

  • OAuth 인증 및 연결 정보: 승인된 채널에 접근하고 예약 작업을 수행하기 위한 액세스 토큰, 갱신 토큰, 승인 권한 및 채널 식별 정보
  • YouTube 채널·영상·재생목록 정보: 채널 선택, 업로드 결과 확인, 제목·설명·썸네일·예약 공개·재생목록 관리
  • YouTube Analytics 및 보고서 데이터: 조회수, 시청 시간, 시청 유지율 등 채널 성과 확인
  • 사용자 제공 자료: 음악, 이미지, 영상, 프롬프트, 프로젝트 설정 등 콘텐츠 제작과 렌더링에 필요한 자료

앱은 YouTube API Services를 이용합니다. Google의 정보 처리는 Google 개인정보처리방침을 따릅니다.

2. 저장 및 보호

앱의 프로젝트, 설정, 미디어 및 분석 기록은 운영자의 로컬 PC에 저장됩니다. YouTube OAuth 연결 정보는 Windows 사용자 기반 암호화로 저장됩니다. Google 계정 비밀번호는 저장하지 않습니다. 로컬 백업을 생성한 경우 백업에도 관련 데이터가 남을 수 있으므로 별도로 관리해야 합니다.

3. 외부 서비스 전달

업로드와 조회 작업에 필요한 정보는 Google·YouTube로 전달됩니다. AI 생성·분석 기능을 실행하거나 예약한 경우 해당 기능에 필요한 프롬프트, 선택한 미디어 및 분석 대상 정보가 설정된 AI 제공업체(예: Google Gemini, xAI)로 전달될 수 있습니다. Midjourney 및 Suno 연동 기능은 선택한 자료와 생성 요청을 해당 서비스로 전달합니다. 각 제공업체의 데이터 처리에는 해당 업체의 약관과 개인정보처리방침이 적용됩니다.

Google 사용자 데이터는 판매하거나 광고 타기팅에 이용하지 않습니다. Google API에서 받은 정보의 이용 및 다른 앱으로의 전송은 Google API 서비스 사용자 데이터 정책과 제한적 사용 요건을 따릅니다.

4. 보관과 삭제

로컬 작업 자료와 분석 기록은 해당 기능의 사용 및 이력 확인을 위해 보관되며, 사용자가 삭제하거나 운영자에게 삭제를 요청할 수 있습니다. 앱에서 YouTube 연결을 해제하면 해당 연결의 저장된 인증정보가 제거됩니다. 연결 해제만으로 기존 프로젝트·미디어·분석 기록이나 YouTube에 업로드된 영상이 모두 삭제되는 것은 아닙니다.

전체 데이터 삭제는 아래 연락처로 요청할 수 있습니다. 운영자는 대상 로컬 데이터와 관련 백업을 확인하여 삭제하며, Google·YouTube에 이미 저장된 콘텐츠는 해당 서비스에서 별도로 관리해야 합니다.

5. Google 접근 권한 철회

앱 내 연결 해제와 별도로 Google 계정의 연결된 앱 관리에서 AI Music의 접근 권한을 철회할 수 있습니다. 철회 후에는 재승인 전까지 해당 권한이 필요한 작업을 수행할 수 없습니다. 접근 권한 철회는 이미 로컬에 저장된 파일을 자동으로 삭제하지 않으므로 필요하면 데이터 삭제도 함께 요청해주세요.

6. 공개 안내 페이지

이 안내 사이트는 로그인 폼, 자체 분석 추적 스크립트 또는 광고를 사용하지 않습니다. GitHub Pages 호스팅 과정에서 IP 주소 등 접속 정보가 처리될 수 있으며, 이는 GitHub 개인정보처리방침을 따릅니다. 로컬 앱의 DB나 인증정보는 이 안내 페이지에 포함하지 않습니다.
